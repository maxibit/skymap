# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-24

## Context

The project is a learning and portfolio project. The reasoning behind each choice is as
valuable as the code, and it must be possible to explain and revisit decisions later.

## Decision

Record every significant decision as a short Markdown ADR in `docs/adr/`, numbered
sequentially, using the format in `template.md`.

## Consequences

- Decisions are reviewable in pull requests like code.
- Changing a decision requires a new ADR that supersedes the old one.
